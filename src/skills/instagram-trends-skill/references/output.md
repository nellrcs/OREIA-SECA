# Apresentação do Output Final

## Estrutura de entrega

Sempre apresente o resultado completo em uma única resposta, nesta ordem:

---

### 1. Resumo das tendências encontradas

```
📊 TENDÊNCIAS PESQUISADAS — [Tema]

1. [Nome da tendência] — [dado concreto]
2. [Nome da tendência] — [dado concreto]
3. [Nome da tendência] — [dado concreto]

✅ Tendência escolhida para o post: [Nome]
```

---

### 2. Visual do post

Exiba o SVG ou HTML gerado diretamente no chat.
Abaixo do visual, informe: `Formato: [1:1 / 4:5 / 9:16] | Tema: [nome do tema visual]`

---

### 3. Legenda completa

Use um bloco de código ou separador claro para facilitar o copy:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📝 LEGENDA — copie e cole no Instagram
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Gancho impactante aqui]

[Desenvolvimento com valor]

[CTA claro]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

### 4. Hashtags

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
#️⃣  HASHTAGS (copie o bloco completo)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
#hashtag1 #hashtag2 #hashtag3 ...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

### 5. Sugestão de publicação

```
⏰ MELHOR HORÁRIO PARA PUBLICAR
   Dias:     [ex: Terça, Quinta, Sexta]
   Horário:  [ex: 11h–13h ou 19h–21h]
   Fuso:     Brasília (BRT)
```

---

## Tom de entrega

- Seja direto — o usuário quer conteúdo pronto para usar
- Ofereça 1 variação da legenda se o tom permitir (ex: versão mais curta)
- Ao final, pergunte se quer ajustar algo: tom, cor, formato, ou pesquisar outro ângulo

## Erros a evitar

- ❌ Não entregue a legenda sem o visual
- ❌ Não entregue o visual sem a legenda
- ❌ Não deixe hashtags sem separar por relevância
- ❌ Não esqueça o CTA na legenda
- ❌ Nunca entregue mais de 30 hashtags (limite do Instagram)
