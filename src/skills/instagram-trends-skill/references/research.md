# Pesquisa de Tendências

## Objetivo
Encontrar as 3 a 5 tendências mais relevantes e recentes sobre o tema informado,
com dados concretos para embasar o conteúdo do post.

## Como pesquisar

### Passo 1 — Busca principal
Use a ferramenta de web_search com queries variadas:

```
"{tema} tendências 2025"
"{tema} trend instagram"
"{tema} viral reels"
"o que está em alta {tema}"
```

### Passo 2 — Busca de dados de engajamento
Complemente com buscas sobre comportamento do público:

```
"{tema} dados mercado brasil"
"{tema} crescimento interesse"
"hashtag {tema} instagram popular"
```

### Passo 3 — Síntese das tendências

Para cada tendência encontrada, extraia:

| Campo | O que capturar |
|---|---|
| **Nome** | Título curto e marcante |
| **Por que está em alta** | Contexto em 1-2 frases |
| **Dado de apoio** | Número, porcentagem ou fato concreto |
| **Ângulo para o post** | Como transformar em conteúdo |

### Exemplo de tendência bem estruturada

```
Tendência: "Slow Fashion consciente"
Por que está em alta: Consumidores buscam peças duráveis após críticas à fast fashion.
Dado: Buscas por "roupa sustentável" cresceram 67% no Google em 2024.
Ângulo: Post educativo "5 motivos para comprar menos e melhor"
```

## Critérios de qualidade

- ✅ Tendência tem menos de 6 meses
- ✅ Tem pelo menos 1 dado concreto de apoio
- ✅ É relevante para o nicho informado
- ✅ Gera valor para o seguidor (não é só promocional)
- ❌ Evite tendências genéricas sem dados
- ❌ Evite informações sem fonte verificável

## Output esperado desta etapa

Liste as tendências encontradas em formato resumido antes de continuar para
a criação do conteúdo. Apresente ao usuário e confirme qual tendência
usar como base do post (ou se quer combinar mais de uma).
