# Criação de Conteúdo Textual

## Legenda (caption)

### Estrutura obrigatória

```
[GANCHO]         ← primeira linha — para o scroll
[DESENVOLVIMENTO] ← valor real, informação ou emoção
[CTA]            ← chamada pra ação clara
```

### Regras por tom de marca

**Divertido/Descontraído**
- Use emojis com moderação (3-5 por legenda)
- Linguagem informal, gírias do nicho
- CTA leve: "Salva esse post! 🔖" / "Marca aquele amigo que precisa ver isso"

**Profissional/Educativo**
- Emojis funcionais como marcadores (▶️ ✅ 📌)
- Linguagem clara e direta
- CTA com autoridade: "Salve para consultar depois" / "Conta pra gente nos comentários"

**Inspiracional**
- Frase de impacto na primeira linha
- Narrativa pessoal ou storytelling curto
- CTA emocional: "Qual dessas te representa?" / "Escreve nos comentários ✍️"

### Tamanho ideal

| Formato | Caracteres | Observação |
|---|---|---|
| Feed educativo | 800–1500 | Pode usar quebras de linha |
| Feed inspiracional | 150–400 | Menos é mais |
| Carrossel | 100–300 | Legenda complementa os slides |
| Stories | Não se aplica | Texto fica no próprio sticker |

### Ganchos que convertem (exemplos)

- "Você ainda não sabe disso sobre [tema]?"
- "[Número] coisas que mudaram em [tema] esse ano"
- "Por que todo mundo está falando de [tendência]"
- "Erro que 90% das pessoas cometem em [tema]"
- "A verdade sobre [tema] que ninguém te conta"

## Hashtags

### Mix recomendado (20-30 hashtags)

| Tipo | Quantidade | Seguidores da hashtag |
|---|---|---|
| **Nicho** (alta) | 5 | > 1M |
| **Nicho** (média) | 8 | 100k – 1M |
| **Nicho** (baixa) | 7 | 10k – 100k |
| **Marca/CTA** | 3-5 | variável |
| **Localização** | 2-3 | se aplicável |

### Como montar

1. 5 hashtags genéricas do tema (alta visibilidade)
2. 8 hashtags específicas do nicho (competição média)
3. 7 hashtags muito específicas (menor competição, mais engajamento qualificado)
4. 3 de localização se o negócio for local (ex: `#moda #modabrasil #modasp`)

### Exemplo para "moda sustentável"

```
Alta: #moda #sustentabilidade #slowfashion #modaconsciente #estilo
Média: #modaeticamente #consumoconsciente #fashionrevolution #ecomoda
Baixa: #capsulewardrobe #modaduradoura #compremenoscompremais
Local: #modabrasil #modabrasileira #modabr
```
